# RiftTrace v1.0.0

RiftTrace v1.0.0 is the first complete,
production-hardened release of the counterfactual
cyber-risk simulation and business-impact
prioritization platform.

## Highlights

The release includes:

- environment graph modeling
- security-aware attack propagation
- identity and credential propagation
- business-impact analysis
- counterfactual analysis
- security-control simulation
- remediation prioritization
- ATT&CK annotation
- attack-path intelligence
- scenario history
- evaluation and benchmarking
- environment ingestion and reporting
- authenticated multi-organization access
- automated testing and CI
- production-style Docker deployment
- operational health checks
- structured request logging
- grouped application navigation

## Research Interpretation

RiftTrace does not claim to predict exact future
attacks.

Results represent modeled potential consequences
derived from supplied environment data and
simulation assumptions.

Connectivity must not be interpreted as automatic
exploitability.

## Production Stack

The production-style stack uses:

- React
- Nginx
- Gunicorn
- Django REST Framework
- PostgreSQL
- Docker Compose

## Quality

v1.0.0 requires all RiftTrace quality gates and CI
jobs to pass before release.
