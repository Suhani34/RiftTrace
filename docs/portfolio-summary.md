# RiftTrace Portfolio Summary

## Project

RiftTrace — Counterfactual Cyber Risk Simulation and
Business Impact Prioritization Platform

## Description

Designed and developed a full-stack cybersecurity
simulation platform that models organizational
assets, vulnerabilities, identities, business
dependencies and security controls as a graph.

Built deterministic attack-propagation and
counterfactual simulation capabilities to evaluate
potential technical reachability, business impact
and remediation alternatives.

## Technical Work

Implemented:

- Django REST APIs
- PostgreSQL persistence
- React and TypeScript frontend
- graph-based simulation using NetworkX
- security-aware propagation
- privilege modeling
- identity and credential propagation
- business-impact analysis
- counterfactual simulation
- remediation ranking
- ATT&CK annotation
- attack-path and chokepoint analysis
- JSON/CSV ingestion
- reporting
- evaluation and benchmarking
- session authentication
- CSRF protection
- organization isolation
- automated frontend/backend testing
- GitHub Actions CI
- Docker production deployment
- Gunicorn
- Nginx
- health checks
- structured logging

## Engineering Principles

The project emphasizes:

- deterministic behavior
- separation between connectivity and exploitability
- immutable simulation inputs
- bounded graph traversal
- reproducible evaluation
- secure authentication
- data integrity
- automated quality gates
- production-style deployment
